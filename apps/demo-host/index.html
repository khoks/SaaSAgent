SaaS Agent — demo host
runtime: http://localhost:8080

Mock host SaaS

This page stands in for a host SaaS application (e-commerce, travel, etc.). The agent panel on the right is the embedded <saas-agent> Web Component shell connected to a local runtime over SSE + WebSocket.

Try it

  • Start the runtime in another terminal: SAAS_AGENT_PORT=8080 pnpm --filter @saasagent/runtime exec node dist/index.js (with ANTHROPIC_API_KEY in scope to use the real Haiku composer).
  • The agent panel auto-opens an SSE channel and renders a welcome layout from the runtime.
  • Click any button in the agent panel — the click round-trips as a typed-JSON InstructionEnvelope over WebSocket; the runtime re-composes; the new layout streams back.
  • If the runtime isn't running, the panel shows SaaSAgent shell placeholder text and connection errors are logged to the browser devtools console.
